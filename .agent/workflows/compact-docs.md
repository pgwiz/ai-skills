# /compact-docs

1. Load and execute `.agent/skills/dev-md-compactor/SKILL.md` (or the globally installed `dev-md-compactor` skill).
2. Run the deterministic compactor script:
   ```bash
   python .agent/skills/dev-md-compactor/scripts/run_compactor.py
   ```
3. If `dev_md_guides/` does not exist yet at project root, it will be automatically created and seeded.
4. Read all files in `dev_md_guides/` before applying qualitative LLM enrichment.
5. Apply per-file update rules:
   - `structure.md`: Fully regenerated by the script.
   - `branch.md`: Fully overwritten with active branch, divergence, and uncommitted diffs.
   - `changelog.md`: Append-only session audit with AST diffs.
   - `features.md`: Surgically update status (Done / In Progress / Planned / Removed).
   - `memory.md`: Append new durable ADRs, gotchas, or conventions.
6. Report a concise 3–5 line summary of the update to chat. Do not output raw file dumps.

Trigger this workflow proactively at task completion boundaries, before git branch merges, or when approaching token limits.
